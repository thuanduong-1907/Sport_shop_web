## Cấu trúc thư mục:
- index.html: Trang chủ
- shop.html: Danh mục sản phẩm
- detail.html: Chi tiết sản phẩm
- checkout.html: Giỏ hàng và đặt hàng
- Styles/style.css: File định dạng giao diện CSS
- Scripts/main.js: File xử lý logic giỏ hàng JavaScript
- Images/: Thư mục chứa hình ảnh
- Sounds/: Thư mục chứa âm thanh
- Videos/: Thư mục chứa video demo chạy bài thực hành (.mp4)
